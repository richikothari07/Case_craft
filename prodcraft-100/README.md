# CaseCraft — 100 Product Intelligence

Batch 01 + 02 + 03 + 04 + 05 contain 50 deep dives:
Blinkit, Zepto, Swiggy, Zomato, PhonePe, Groww, Zerodha, CRED, Meesho, Razorpay.

## Run locally
npm install
npm run dev

## Deploy to Vercel
Import the repository. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

No API key or backend is required for this version. The research content is bundled into the frontend.

## Quality standard
Each case is structured around:
- What the product does
- Differentiator / moat
- Product teardown
- Metrics
- Improvements
- Interview questions
- Evidence and source links

Public facts are separated from PM recommendations. Metrics are only included where publicly supported; qualitative metric trees are used where private data is unavailable.
