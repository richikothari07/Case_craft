# CaseCraft

CaseCraft is a 50-product Indian product intelligence library.

## Run locally

npm install
npm run dev

## Vercel / GitHub

The repository root must contain `package.json`, `index.html`, and `src/` directly.
Do not upload the `prodcraft-100` folder as a nested folder inside the repository.

Build command: `npm run build`
Output directory: `dist`

## Contents

50 product case studies with product thesis, moat analysis, teardown, growth loops, metrics, PM improvement bets, interview questions, and evidence/source trails.
